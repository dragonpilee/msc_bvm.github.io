## 🏆 About

**Coding Duo** is a coding event where participants showcase their programming skills and compete in various challenges. Organized by the Department of Computer Science (MSc CS) at BVM Holy Cross College, Cherpunkal, the event aims to foster creativity, problem-solving, and teamwork among coding enthusiasts.
